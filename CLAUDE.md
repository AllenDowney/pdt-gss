# Working in pdt-gss

This repo holds GSS metadata built to the PublicDataToolkit standard. The standard is `../PublicDataToolkit/STANDARD.md`; read it before changing records.

- `metadata/releases/`, `metadata/groups.jsonl`, `metadata/annotations/`, `metadata/derived/` and `build/report.md` are generated by `build/build_slice.py`. Don't edit them; change the build or `build/slice.yaml`.
- `metadata/corrections.jsonl`, `dataset.yaml`, `sources.yaml`, `EXTENSIONS.md` and `build/slice.yaml` are edited by hand.
- `data/` is gitignored and never committed.
- Run `make build` then `make check` (use the CultureWar conda env, or any env with pandas, PyYAML and jsonschema).
- Terms questions go to Allen; don't decide them.
